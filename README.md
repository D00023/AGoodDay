## 📖 写在前面

近日，网络上掀起了一股神秘的养生潮流——**「三大理论」**：

> 少喝奶茶多喝水，练出线条别练块，每天睡满八小时。

道理我都懂，但……**谁来帮我记着啊？**

于是有了 **AGoodDay**：把「三大理论」变成一场**可打卡、可升级、可炫耀**的修行游戏。
喝口水是修行，拉个伸是渡劫，睡个饱觉是飞升。

**数据全部存在你自己的浏览器里**——没有账号、没有服务器、没有大数据杀熟，只有你的修行记录。

## 🚀 快速开始

**方式一：直接打开（最快）**

双击 `index.html`，即刻开始修行。无需安装、无需构建、无需 Node。

**方式二：本地起服务（体验完整 PWA）**

```bash
cd AGoodDay
py -m http.server 8080
# 或：npx serve .
```

浏览器打开 `http://localhost:8080`，手机同网段访问 `http://<电脑IP>:8080`，即可「添加到主屏幕」。

**方式三：部署上线（推荐）**

任何静态托管都能放：GitHub Pages / Vercel / Netlify / IGA Pages……
推上去就是一款可安装的在线 APP，发给朋友装到手机上卷死他们。

## 🗂 项目结构

```
AGoodDay/
├── index.html            # 页面骨架（四大模块 SPA）
├── styles.css            # 设计系统：Token 化配色 / 组件 / 动效
├── app.js                # 交互与渲染逻辑
├── mock.js               # 全部假数据与常量（改这里调目标值/等级/文案）
├── api.js                # 接口桩：将来接真实后端只改这一个文件
├── manifest.webmanifest  # PWA 应用清单
├── sw.js                 # Service Worker：离线缓存 + 版本更新
└── icons/                # 定制图标（墨底鎏金印 + 三色理论条）
```

**技术栈**：原生 HTML + CSS + JavaScript。无框架、无构建、无依赖——养生项目，主打一个心平气和。

## 🔧 自定义

想改成自己的修行目标？打开 `mock.js`，全部参数一目了然：

```js
goals: { water: 2000, move: 30, sleep: 8 },   // 三大理论目标值
ranks: [ { name: '见习学徒', min: 0 }, ... ],  // 修为境界
comments: [ '理论尚未开悟……' ],               // 每日批注（可整活）
```

发布新版本后，把 `sw.js` 里的 `CACHE_NAME` 版本号 +1，用户刷新即完成静默更新。
